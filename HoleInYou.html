HoleIn you

Ce jeu à été réalisé lors de la fight april jam 2026 avec le thème "All In"

Il a été réalisé en duo avec Arthur Queste

La gam jam a eu lieu sur un mois pendant notre période de stage

Jeu disponnible sur itch.io

Outils utilisés

Moteur de jeu : Unity

Outil de partage de code : github

Visuels : Aseprite

Langage : c#

L'univers

Le jeu se passe dans un monde qui est un mélange entre steampunk et fantasy

Le gameplay

Les personnages peuvent donner deux coups de poings différents

Ils peuvent s'accroupir et sauter haut diagonale

Ils ont aussi accès à une parade qui provoque une contre attaque si activée au bon moment
